# Observability

ForgeDB v0.9 adds lightweight in-process metrics intended for debugging, demos and benchmarks.

Counters include SQL statements, CRUD operations, transactions, commits, rollbacks, index lookups and table scans.

Use `:metrics` in the interactive CLI:

```text
forge> :metrics
ForgeDB metrics:
  statements=...
  selects=...
  inserts=...
  updates=...
  deletes=...
  transactions=...
  commits=...
  rollbacks=...
  index_lookups=...
  table_scans=...
```

The metrics are intentionally non-durable: they describe the current process rather than database state.
