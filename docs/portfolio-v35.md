# Portfolio & Interview Layer

This layer turns ForgeDB's engineering work into reusable career-facing material without changing core database semantics.

## Deliverables

- `docs/portfolio/project-case-study-v35.md` - project story and scope
- `docs/portfolio/interview-guide-v35.md` - technical interview preparation
- `docs/portfolio/cv-linkedin-project-bullets-v35.md` - concise project wording
- `docs/portfolio/github-project-description-v35.md` - repository positioning
- `docs/portfolio/design-tradeoffs-v35.md` - engineering decisions and trade-offs

## Positioning

ForgeDB demonstrates systems thinking across language processing, query engines, storage, transactions, reliability, security, observability and software delivery.

## Scope discipline

The project is presented as a portfolio-scale educational database engine, not as a production replacement for mature relational databases.
